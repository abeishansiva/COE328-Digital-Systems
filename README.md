# COE 328 – Digital Systems

COE 328 lab projects (Intel/Altera Quartus II, VHDL and schematic design, Cyclone II `EP2C35F672C6`).

| Lab | Topic |
|---|---|
| [Lab 1](Coe-328_lab1) | Intro to Quartus and VHDL (3 parts) |
| [Lab 2](coe328_lab2) | Schematic design and simulation |
| [Lab 3](coe328_lab3) | 4-bit adder/subtractor and 7-segment display |
| [Lab 4](coe_328_lab4) | Decoder, encoder, multiplexer and Johnson counter |
| [Lab 5](coe328_lab5) | Finite state machine (student ID sequencer) |
| [Lab 6](coe328_lab6) | Decoder, latch, ALU and FSM designs |

Each lab folder has its own README. Open a `.qpf` project file in Quartus II to compile and simulate.
